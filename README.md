# David Barske — Profile

Static public profile and editorial site for David Barske, published through GitHub Pages.

## Deployment

GitHub Pages publishes from the `main` branch and `/docs` folder.

## Public routes

- Profile: `https://davidbarske.github.io/Profile/`
- Students, Syndicates & Shredders: `https://davidbarske.github.io/Profile/students-syndicates-shredders/`
- The Privilege of Probability: `https://davidbarske.github.io/Profile/privilege-of-probability/`

## Site structure

- `docs/index.html` — profile, writing shelf, interview, thinking models, ventures, projects and toolkits
- `docs/students-syndicates-shredders/` — Field Notes interactive visual essay
- `docs/privilege-of-probability/` — Independent Opinions interactive visual essay
- `docs/assets/` — shared CSS and JavaScript
- `docs/downloads/` — CV and article PDFs

Google Analytics uses property `G-19KLFX5LNG` across the public pages. Both article routes provide direct PDF downloads, article-to-article navigation, share/print/respond actions and mobile navigation.

The repository preserves prior versions through Git commit history.
